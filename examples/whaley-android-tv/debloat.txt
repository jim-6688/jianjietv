# 微鲸 (Whaley) Android 电视 起始去广告清单 (whaley-android-tv)

# 状态: 起始清单 (starter)。通用部分已实测安全; 微鲸专属部分默认注释, 需真机确认后启用。

#   枚举真机包名: TV_HOST=<IP> tools/tv.py "pm list packages | grep -i whaley"
#   停用:         TV_HOST=<IP> tools/disable.sh examples/whaley-android-tv/debloat.txt
#   守护:         TV_HOST=<IP> tools/guard.py  examples/whaley-android-tv/debloat.txt
#
# 适配指南见 docs/devices/zh-cn-domestic-android-tv.md。
